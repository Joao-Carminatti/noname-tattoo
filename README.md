# NONAME TATTOO

Next.js (App Router) + TypeScript + Tailwind v4. Deploy: Vercel.

```bash
npm install
npm run dev
```

## Reaproveitar em outro estúdio
1. `src/data/site.ts`: nome, endereço, contatos, horários.
2. `src/app/globals.css`: tokens de cor (`@theme`).
3. `src/fonts/`: troque as fontes e ajuste `layout.tsx`.

Valores `[PENDENTE]` em `site.ts` devem ser confirmados com o cliente antes de publicar.

## Pendências antes de publicar
Procure `[PENDENTE]` em `src/` e substitua: WhatsApp, horários, domínio (`site.url`), artistas, fotos do portfólio (`/public/portfolio` + `src` em `data/portfolio.ts`), bio, respostas do FAQ, depoimentos autorizados, `/public/og.jpg`.
